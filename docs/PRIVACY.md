# 隐私说明

默认 Tesseract 流程本地处理，不上传聊天、不调用 AI、不解析聊天数据库。安装依赖会联网；使用者提供的外部 OCR 命令可能联网或上传图片，须自行检查。

## 本地敏感文件

- `config.json`：聊天对象名及左右身份。
- `work/`：所选窗口标题、原图、OCR 中间图和文本等调试信息。
- `导出结果/`：正文、质量报告及可选 TXT、JSON、统计或分片。
- 私人测试、日志、备份、截图、环境文件和压缩包。

这些内容可能包含第三方个人信息。公开仓库只保留代码、说明、许可、完全虚构示例和空导出目录占位。运行工具以后仍会生成新的敏感文件。

工具没有自动匿名化或安全擦除保证。删除工作区文件也不等于磁盘级安全擦除；分享前应对照内容核查，不能只改文件名。

## 发布规则

.gitignore 使用明确白名单。新增文件默认忽略，人工审阅后才放行。许可证及虚构示例被明确允许，不把所有 JSON 或图片整体放开。

不强制添加私人文件，不上传父工作目录，不压缩整个运行目录分享。ZIP、网页上传不会自动遵循 Git 忽略规则。

忽略规则对已跟踪文件及历史无效。提交前检查完整暂存内容，旧仓库还需检查全部分支、标签和历史。曾公开的隐私不能仅靠删除本地文件撤回。

灵感截图不随源码分发；其脱敏与转载权限需单独确认，项目 MIT License 不覆盖第三方图片。不要把本地 Release 预览当成已经批准公开的图片附件。

群聊或其他窗口可能包含无关人员信息。交给 AI 属于主动分享，须确认访问及分享权限，核对内容并按需匿名化。

检查步骤见 [发布清单](GIT_RELEASE_CHECKLIST.md)。
