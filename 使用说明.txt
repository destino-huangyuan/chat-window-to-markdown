聊天窗口截图转文本工具 v1.0 — Verified

本地截图与 OCR 整理工具，不是无损备份或 AI 分析软件。
主要验证环境为 Windows 11、微信私聊；其他 Windows 版本、群聊及其他
聊天软件未经过相同验收。目标聊天软件不是本工具的安装依赖。

首次安装：
1. 下载项目完整 ZIP 后先解压，进入包含 README 和几个 .bat 的目录。
   放在自己的可写文件夹，不要从 ZIP 或系统只读目录直接运行。
2. 从 https://www.python.org/downloads/windows/ 安装 Python 3.10+。
   按安装器提示配置命令访问方式。重新打开命令提示符，检查
   py -3 --version；没有 py 时检查 python --version。
   应显示至少 3.10 的版本，不能只是打开应用商店或提示未安装。
3. 双击 install_dependencies.bat，联网安装 Pillow，等待安装完成。
   若失败先处理报错；不要用另一个 Python 环境的 pip 代替。
4. 按 https://tesseract-ocr.github.io/tessdoc/Installation.html#windows
   的 Windows 指引安装外部 Tesseract。它不是 Windows 自带组件。
   需要 chi_sim、eng 语言数据，放在其 tessdata 目录。
   语言数据下载和自定义程序路径见 README.md。
5. 双击 diagnose_ocr.bat，确认 Python 版本、Pillow: OK、Tesseract，
   以及语言列表中独立的 chi_sim 和 eng。缺少任意一项先处理。
   诊断不是安装器，也不验证目标聊天界面适配；不能只看退出码。

首次使用：
1. 打开聊天窗口，手动滚动到采集起点，确保自己有权读取和分享内容。
2. 双击“开始导出微信聊天.bat”，选择窗口、左右身份及对象名。
3. 移开遮挡目标聊天的运行窗口及其他窗口，再按回车开始。
4. 采集时不要移动、缩放、最小化、手动滚动或切换聊天。
5. 首次建议在工具目录的命令提示符中只采集少量页：
   开始导出微信聊天.bat --max-pages 5 --keep-screenshots
   确认原图及导出正常后，再采集所需内容。
6. Ctrl+C 可提前停止，已写出文件保留，但不能断点续跑。
7. 完成后双击“打开导出结果.bat”。它只打开文件夹，不生成聊天记录。

查看与复核：
- 默认生成聊天正文和质量报告两份 Markdown。
- 可用记事本打开 .md 文件，也可用已有 Markdown 工具预览。
- 先读质量报告，再对照正文与原图。疑似问题不等于确认错误。
- 原图位于 work/wechat_chat_exporter/运行时间/screenshots/。
  报告中的 page_001.png 等是页名，需在该目录自行查找。
- 正常结束默认保留前 300 页；需要全部原图时提前加 --keep-screenshots。
- examples 的配套示例完全虚构，不包含真实聊天或截图。

注意：
- 换对象时用 --target-name、--self-position 覆盖旧配置，
  或删除本地 config.json 后重新确认。完整命令见 README.md。
- 可能仍有重复、漏字、漏行、类型与发送者误判，报告也可能漏报误报。
- 时间通常继承界面分隔符，不等于每条消息的精确发送时间。
- 群聊左右布局不能可靠识别每位成员，不要据此判断具体发言人。
- 其他应用的默认裁剪与消息规则可能不适配，不是全平台导出器。
- 全新 Windows 首次安装和采集完整路径尚未独立实测。
- 不要上传私人截图、导出、配置、日志或整个运行目录。
- 默认本地处理；自定义 OCR 如果调用云服务，图片可能离开本机。
