# 聊天窗口截图转文本工具

**v1.0 — Verified** · 功能封版：2026-10-10

将一个可见聊天窗口，通过滚动截图和本地 OCR，整理成可阅读、可交给任意 AI 的 Markdown 文件。默认使用外部 Tesseract，不依赖聊天软件的数据接口，不解析聊天数据库，不内置 AI 分析，不自动上传聊天内容。

Verified 表示微信聊天样本经过本地自动检查及人工验收，不表示 OCR 无错漏，也不表示所有聊天软件均已适配。

## 采集对象与适配范围

截图和 OCR 并不绑定微信。窗口选择会列出其他符合条件的可见桌面窗口，不要求窗口必须属于微信。用户可以选择其他聊天应用窗口尝试采集。

但当前默认裁剪、绿色/灰色气泡、时间分隔符及红包、小程序等识别规则主要按微信界面设计。其他应用可能需要调整裁剪和参数，消息分组、发送者、时间及非文本类型也可能无法可靠识别。因此本版是“以微信为已验证场景的聊天窗口截图工具”，不是已经验证过的全平台聊天导出器。

目标聊天软件只是采集对象，不是本工具的安装依赖。现有文件名和启动入口保留“微信”字样，方便沿用旧入口；它们不代表依赖微信接口。

## 已有能力

- 默认约半屏滚动采集，按界面顺序导出。
- 私聊左右身份配置，同气泡多行合并，保守跨页去重。
- 可识别的图片、表情、卡片等非文本消息使用占位符。
- 可疑时间标为待核对，不参与可信聊天周期统计。
- 质量报告提示疑似重复、截断、发送者归属异常、时间异常及来源页。
- 每页保存进度；窗口关闭、无新增或截图持续不变时自动停止。

## 安装

本工具本身的运行依赖：Windows、Python 3.10+、Pillow，以及默认 OCR 引擎 Tesseract。Windows 是当前系统要求，因为窗口采集与滚动使用 Windows 系统接口。

主要验证环境为 Windows 11、Python 3.14.6、Pillow 12.3.0、Tesseract 5.5.0。Python 3.10+ 是声明的运行要求，不表示每个版本组合都经过测试。

### 1. 下载并解压工具

在项目仓库页面选择 **Code > Download ZIP**，下载后先解压。进入包含 `README.md`、`requirements.txt` 和启动批处理的目录，放在自己的可写文件夹中。

不要在 ZIP 内直接运行，也不要放在需要管理员权限才能写入的系统目录。普通使用者不需要安装 Git。本工具会在自身目录保存配置、截图和导出文件。

### 2. 安装 Python

从 [Python Windows 官方下载页](https://www.python.org/downloads/windows/) 安装 Python 3.10 或更高版本。选择适合电脑架构的安装程序，不要使用用于嵌入开发的 embeddable package。

按照对应安装器提示设置命令访问方式。传统安装器若提供 `Add python.exe to PATH`，可勾选；使用 Python 安装管理器时，按其提示安装运行时。不同安装器的选项可能不同，详见 [官方 Windows 使用说明](https://docs.python.org/3/using/windows.html)。

安装后重新打开命令提示符：按 Win+R，输入 `cmd` 并回车，检查：

```bat
py -3 --version
```

没有 `py` 时检查 `python --version`。应输出至少为 3.10 的版本。若只是打开应用商店、找不到命令，或提示没有已安装 Python，说明运行时或命令配置尚未完成，先修复再继续。

### 3. 安装 Pillow

双击 `install_dependencies.bat`，等待安装完成。需要联网；看到 `Successfully installed` 或 `Requirement already satisfied` 后，按任意键关闭窗口。

若出现安装失败、连接失败或找不到 Python，不要直接开始导出，按 [排查说明](docs/TROUBLESHOOTING.md) 处理。

批处理优先使用 `py -3`，不存在时使用 `python`。手动安装时，在工具目录的命令提示符中使用同一个解释器：

```bat
py -3 -m pip install -r requirements.txt
```

没有 `py` 时换成 `python`。不要只用另一个环境中的 `pip` 安装，否则启动时仍可能找不到 Pillow。

### 4. 安装 Tesseract 和语言数据

Tesseract 不是 Windows 自带组件，也不随仓库分发。从 [Tesseract 项目安装指引的 Windows 小节](https://tesseract-ocr.github.io/tessdoc/Installation.html#windows) 进入其引用的 Windows 分发入口，选择适合电脑的安装器。该安装器由相应分发方提供，不是本工具制作的安装包。

默认识别组合为 `chi_sim+eng`，安装后必须能找到简体中文 `chi_sim` 和英文 `eng` 两份语言数据。安装器提供语言选项时选择相应语言；若缺少语言数据，可从 [Tesseract 官方语言数据仓库](https://github.com/tesseract-ocr/tessdata_fast) 下载 `chi_sim.traineddata` 和 `eng.traineddata` 文件，放入所安装 Tesseract 的 `tessdata` 目录。下载实际文件，不要把网页或 ZIP 改名为 `.traineddata`。

常见目录是 `C:\Program Files\Tesseract-OCR\tessdata`，以实际安装位置为准。写入系统目录可能需要管理员批准；使用语言数据仓库时，其内容应与安装的引擎版本兼容，本工具没有捆绑或测试所有第三方分发组合。

如果安装在自定义目录，在工具目录的命令提示符中这样启动：

```bat
开始导出微信聊天.bat --tesseract-path "D:\Tools\Tesseract-OCR\tesseract.exe"
```

### 5. 运行环境诊断

双击 `diagnose_ocr.bat`，确认窗口显示：

- Python 版本至少为 3.10。
- `Pillow: OK`。
- 找到 Tesseract，并且语言列表中分别有 `chi_sim` 和 `eng`。

看到 Tesseract 路径不代表语言包齐全。缺少其中一份时，默认语言组合仍不能正常使用。诊断脚本不是一键安装器，也不检查聊天软件的界面是否适配；不能仅凭它的退出码判断成功，应阅读实际提示。

诊断主要检查 PATH 和常见默认安装位置；找不到自定义位置不代表主程序不能调用。可直接验证：

```bat
"D:\Tools\Tesseract-OCR\tesseract.exe" --list-langs
```

更多语言与外部 OCR 接口见 [OCR 接入说明](docs/OCR_ADAPTER.md)。本版不附带第三方适配器或模型。

完成运行依赖安装后，再打开要采集的应用窗口。是否安装微信取决于你要采集什么，不是安装本工具的步骤。

## 使用

1. 打开聊天窗口，手动滚动到采集起点。工具从当前可见内容向下采集，不会自动找到历史最开头。
2. 保持窗口可见，双击 `开始导出微信聊天.bat`。
3. 选择窗口，首次确认“我”在左侧还是右侧，并填写聊天对象名。
4. 移开遮挡目标聊天内容的运行窗口和其他窗口，再按回车开始。当前程序提示中仍有“微信”字样，应以你实际选中的目标窗口为准。
5. 采集期间不要移动、缩放、最小化、手动滚动或切换聊天。
6. 完成后双击 `打开导出结果.bat`。先看质量报告，再对照截图核对正文。

名称和左右身份保存在本地 `config.json`。换聊天时显式覆盖，或删除配置后重新确认：

```bat
开始导出微信聊天.bat --target-name "示例对象" --self-position right
```

首次试用建议先采集少量页。在工具目录的命令提示符中运行：

```bat
开始导出微信聊天.bat --max-pages 5 --keep-screenshots
```

确认原图、发送者和导出结果正常后，再双击启动入口采集所需内容。提前结束可在运行窗口按 Ctrl+C，此前写出的进度会保留；这不是断点续跑。

尝试其他窗口时，可通过标题选择，关闭微信专用侧栏自动裁剪，并自行设置内容边距。例如下面的标题和边距只是参数示例，不代表对该窗口已完成适配：

```bat
开始导出微信聊天.bat --window-title "目标窗口标题" --no-auto-chat-panel --content-inset 0,80,0,180 --max-pages 5
```

边距依次为左、上、右、下；需根据实际窗口调整。先检查这几页原图及导出，尤其是发送者归属，不能仅以程序运行成功判断适配成功。

## 输出与复核

默认只生成两份 Markdown，位于 `导出结果/`：

- `对象_聊天记录_完整_时间.md`：主要成品，含顺序、身份、可识别时间和基础统计。
- `对象_质量检查_时间.md`：人工复核清单，含原因和截图页码。

Markdown 是文本文件，可以右键选择“打开方式”并用记事本查看；已有 Markdown 编辑器也可使用预览，不需要为此安装开发工具。质量报告的截图页名不是自动打开原图的按钮。

截图与 OCR 调试信息在 `work/wechat_chat_exporter/运行时间/`，原图在其中的 `screenshots/` 文件夹。按报告中的 `page_001.png` 等页名查找。正常结束默认保留前 300 页原图；需核对更长的记录时，采集前加 `--keep-screenshots`，请预留磁盘空间。

“疑似”不等于确认错误。保守去重可能留下重复，OCR 也可能漏字或漏行，并非每个问题都能被报告发现。优先核对“谁说了什么”及时间线。人工修正成品不会改变算法。

可信时间通常来自最近可识别的界面时间分隔符，不是每条消息的精确发送时间。跨年、相对日期或被截断的时间仍需人工核对。

遗留可选输出按需启用，默认无需使用：

```bat
开始导出微信聊天.bat --keep-txt
开始导出微信聊天.bat --output-json
开始导出微信聊天.bat --split-md
```

完全虚构且相互对应的示例：[正文](examples/sample_chat.md)、[质量报告](examples/sample_quality_report.md)。示例由现有导出函数生成，故意保留部分风险，说明见 [示例说明](examples/README.md)。没有附带真实聊天或截图。

## 已知限制

- 主要经过 Windows 11 和微信私聊场景验证。全新 Windows 从下载到安装、采集的完整路径尚未独立实测；其他 Windows 版本及 Python 版本组合不能视为已验证。
- 微信私聊是主要验收场景。群聊可以采集，但左右身份配置不能可靠区分每位成员，不能据此把左侧内容归给具体成员。其他应用尚未经过相同验收。
- 字词准确率受字体、缩放、截图完整性与 Tesseract 影响；不是无损备份。
- 非文本分类可能误判，不可靠识别图片或表情包里的内容。
- 窗口布局变化可能影响裁剪，漏行时先核对截图。
- 不适合无限导出历史；长时间采集时微信可能关闭或滚动失效，原因尚未确认。
- 不做多窗口管理、数据库读取、情感判断或模型专属格式。

常见故障见 [排查说明](docs/TROUBLESHOOTING.md)。

## 隐私与发布

默认在本机处理。安装依赖需要联网；自定义 OCR 命令由用户提供，若其调用云服务，聊天图片可能离开本机。

运行生成的聊天、截图、私人配置、质量报告和调试文件不能随工具公开。`.gitignore` 使用明确发布白名单，详见 [发布清单](docs/GIT_RELEASE_CHECKLIST.md) 和 [隐私说明](docs/PRIVACY.md)。

忽略规则不会移除已被 Git 跟踪的文件或清理历史。上传前仍需检查暂存区、历史及分享包实际内容。不要直接压缩整个工作目录。

只处理你有权访问和分享的聊天。上传给 AI 属于使用者主动分享，应先复核并按需匿名化。
